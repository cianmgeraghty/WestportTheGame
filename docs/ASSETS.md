# Asset notes

The app icon is an original generated illustration based on the real Westport Clock Tower silhouette and Croagh Patrick.

The local reference photograph used during design is from Wikimedia Commons: [Clock Tower, Westport, Co Mayo](https://commons.wikimedia.org/wiki/File:Clock_Tower,_Westport,_Co_Mayo.jpg). It is retained for design reference only and is not displayed in the app.
